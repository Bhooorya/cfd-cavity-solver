CFD APP - QUICK START

For your friend (from ZIP):
1) Extract the ZIP to any folder.
2) Double-click launch-cfd.bat
3) The app opens in browser.

Notes:
- Keep the black terminal window open while using the app.
- To stop the app, close that terminal or press Ctrl+C.
- If Python is missing, install it from https://www.python.org/downloads/

Optional:
- To use a different port: launch-cfd.bat 8080
